# Security Policy

## Supported Versions

This project is under active development on the `main` branch. Only `main`
is currently supported with security fixes; there are no tagged releases
yet.

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, report it privately by emailing
[maurizio.martignano@gmail.com](mailto:maurizio.martignano@gmail.com) with:

- A description of the vulnerability and its potential impact
- Steps to reproduce, or a proof-of-concept if available
- Any relevant configuration (note: never include real API keys, patient
  data, or other sensitive information in your report)

You should receive an acknowledgement within a few business days. We'll work
with you to understand and address the issue, and to agree on disclosure
timing before any public announcement.

## Scope

This application aggregates and analyzes medical procedure data using
LLM-backed APIs. It is intended for research, validation, and controlled
medical IT environments — it is **not** a certified medical decision system.
Please keep this context in mind when assessing severity, especially for
issues involving data handling of transcripts or generated reports.
